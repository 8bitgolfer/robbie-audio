EQ.

8-Band Parametric Equalizer

A clean, flexible EQ for everything from vocal cleanup to low-end shaping. Move frequency nodes, shape your response and save useful curves for later.

Built around a familiar plugin workflow with the controls you need immediately visible. Adjust, listen, and find your sound.

Key features

  • 8 adjustable frequency bands
  • Bell, low shelf, high shelf, low cut, high cut and notch filters
  • Real-time spectrum display
  • Factory presets plus save/load user presets
  • Undo and redo for recent edits
  • Right-click band reset and type controls
  • Output gain, wet/dry mix and bypass
  • Resizable VST3 interface
DOWNLOAD & INSTALL

Get started.

Download the free source project, build a Release VST3 on Windows, and copy the compiled bundle into your system VST3 directory.

About this prototype release

The downloadable ZIP is the JUCE/C++ source project, not a precompiled installer. It requires Visual Studio 2026, CMake, and Git to compile. The compiled plugin should be tested before use in critical projects or redistribution.
