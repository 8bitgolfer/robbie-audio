INSTALL GUIDE

Windows VST3 setup.

This release requires compiling the source on your own Windows computer.

Prerequisites: Visual Studio 2026 with Desktop development with C++, CMake, and Git.
01
Extract your ZIP

Unzip the selected plugin project into a folder on your computer.

02
Run build-windows.bat

CMake will generate and build the Windows Release plugin. Check the console for a successful result.

03
Copy the VST3 bundle

Find the resulting .vst3 folder under build → [project]_artefacts → Release → VST3 and copy the entire bundle into:

C:\Program Files\Common Files\VST3
04
Rescan in FL Studio

Open Options → Manage plugins → Find installed plugins. Locate EQ or DISTORT and add it to a mixer effect slot.
