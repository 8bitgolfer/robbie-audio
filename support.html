INSTALL GUIDE

Three simple steps.

Once the installer becomes available, installing EQ will only require running the setup file and rescanning your plugins in FL Studio.

Requirements: Windows 64-bit and a VST3-compatible DAW. Close FL Studio before updating an existing plugin.
01
Download EQ Setup

Download EQ by Robbie v1.4 for Windows from this website.

02
Run the setup file

Double-click the .exe and follow the installation wizard. EQ installs into the standard VST3 directory.

C:\Program Files\Common Files\VST3
03
Open FL Studio and rescan

Go to Options → Manage plugins → Find installed plugins. Search for EQ (vendor Robbie).
