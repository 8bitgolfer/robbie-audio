# Robbie Audio — GitHub Pages storefront

Public storefront for EQ by Robbie v1.4 (Windows 64-bit VST3). DISTORT is still in development and is not advertised or distributed here.

## EQ installation

The public release will use a Windows setup executable, not the C++ source ZIP. Visitors will be able to download and run the .exe, complete installation, and rescan in FL Studio. They will not need Visual Studio, CMake, Git, or a batch file.

## Current release status

The EQ Windows installer is stored at `downloads/EQ_by_Robbie_v1.4_Setup.exe`, and the live website links directly to it from the homepage, plugin catalog, EQ page, and support page.

Before publishing, test the installer on Windows, scan it for malware, and confirm the version and uninstall behavior.
